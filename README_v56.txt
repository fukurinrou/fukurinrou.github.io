福林楼 QR注文システム v5.6 セキュリティ修正版
2026-09-06 14:46 変更済み

今回の目的
----------
以前のQR URLをブラウザ履歴・ブックマークから開いて、店外から注文できる問題を防止します。

仕組み
------
1. お客様が着席したら、会計端末の「会計」画面にある「テーブル注文受付」で T1/T2/T3 の「受付開始」を押します。
2. 6桁の店内確認コードが表示されます。
3. お客様はテーブルの固定QRを読み取り、その6桁コードを1回入力して注文開始します。
4. 注文データは、Firebase側でも「受付中・有効期限内・正しいセッションID・正しい6桁コード」を満たさない限り拒否されます。
5. 会計完了すると、そのテーブルの受付は自動終了します。
6. 同じURLを家から履歴で開いても、受付終了後は注文できません。
7. 受付は開始から4時間で自動的に無効になります。
8. tableパラメータのないURLからは注文できません。

上書きするファイル
------------------
- index.html
- staff.html

Firebaseで必ず公開するもの
--------------------------
- firebase_rules_v56.json

重要：
HTMLだけ入れ替えてFirebaseルールを変更しない場合、セキュリティ対策は完成しません。
Realtime Database → Rules に firebase_rules_v56.json の内容を貼り付けて「公開」してください。
